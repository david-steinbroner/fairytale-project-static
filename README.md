# Fairytale Project

A rebuilt website for exploring the Fairytale Project's archive.

The site brings together stories, photographs, and project material in Chinese, English, and German. This version preserves the archive in a static website that can be hosted without the original site's database and publishing system.

[Visit Fairytale Project](https://www.fairytaleproject.net)

## Explore the source

Start with `index.html`. The pages draw on the included archive content and images. There is no frontend build step.

For a local preview, run this from the project folder and open `http://localhost:8000`:

```bash
python3 -m http.server 8000
```

The archive contains a large image collection, so a full checkout can take time. [The project guide](CLAUDE.md) explains how the content and site files fit together.

The [original website source](https://github.com/david-steinbroner/fairytale-project-old-site) is kept separately as a historical reference.
